# Backwards-Organisms Ablation

Test whether top-LLM performance on LUCA reflects genuine causal inference or
transferred structural priors by running models on backwards-inverted organisms
(every signed quantity flipped) and comparing to the paper's forward results.

See the design spec:
`docs/superpowers/specs/2026-04-22-backwards-organisms-ablation-design.md`

## Scope

- **Tier:** medium only (easy is a weak discriminator; hard has backwards
  convergence issues — out of scope).
- **Modes:** both healthy and disease.
- **Seeds:** 20 canonical medium seeds (0–19).
- **Models:** paper's model set (Opus, Sonnet, DeepSeek, Qwen, GPT-5.1, GPT-4o,
  GPT-4.1) + heuristic as null control.

Forward scores are already computed in `experiments/paper_v1/` and joined in
downstream analysis — this runner only generates the backwards half of the
paired comparison.

## Files

- `prescreen.py` — Validate each canonical seed under backwards for each
  (tier, mode) cell. Writes `valid_seeds.json`. No API cost.
- `run.py` — LLM sweep on valid seeds via `evaluate_model(backwards=True)`.
- `valid_seeds.json` — Manifest of seeds that succeed under backwards.
  Generated by `prescreen.py`.
- `analyze.py` — (PR 3) paired stats, Wilcoxon, mixed-effects interaction.
- `plot.py` — (PR 3) Panel A bar chart + Panel B scatter + disease three-panel.
- `results/<mode>/<model>.jsonl` — One record per (seed, model, mode).
- `logs/<mode>/` — Per-session JSON+HTML agent logs. Gitignored.

## Reproducing the sweep

```bash
# 1. Pre-screen (no API cost; just generation):
python experiments/backwards_ablation/prescreen.py

# 2. Heuristic baseline (no API cost):
python experiments/backwards_ablation/run.py --model heuristic

# 3. Full LLM sweep (API cost ~$120–250 total for both modes):
python experiments/backwards_ablation/run.py \
    --model claude-opus-4-6 \
    --model claude-sonnet-4-6 \
    --model deepseek-v3 \
    --model qwen-3.5 \
    --model gpt-5.1 \
    --model gpt-4o \
    --model gpt-4.1

# Single-mode smoke on a subset:
python experiments/backwards_ablation/run.py \
    --model claude-opus-4-6 --mode healthy --n 3
```

## Pre-flight

**Spend gate:** before running the full sweep (step 3 above), confirm with the
LUCA authors that a merged backwards-ablation PR + drafted paper subsection
earns byline credit. The code ships independently of this conversation; the
compute does not.

## Schema

Each JSONL record matches the paper's `evaluate.py` output schema. Joining
forward and backwards records across `experiments/paper_v1/` and
`experiments/backwards_ablation/results/` gives the paired dataset for the
analysis stage.
